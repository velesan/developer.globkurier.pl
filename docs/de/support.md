---
title: Support
---

- **Fehler in der API oder in dieser Dokumentation**: [Issue eröffnen](https://github.com/velesan/developer.globkurier.pl/issues/new/choose).
  Geben Sie den Endpunkt, die Umgebung (Produktion / Test), den Zeitpunkt der Anfrage und die erhaltene Antwort an.
- **Sicherheitslücke**: Eröffnen Sie kein öffentliches Issue, folgen Sie [SECURITY.md](https://github.com/velesan/developer.globkurier.pl/blob/main/SECURITY.md).

!!! warning "Achtung"
    Issues sind öffentlich. Entfernen Sie Tokens, Passwörter und personenbezogene Daten von Empfängern, bevor Sie etwas veröffentlichen.
