# Security policy

Do not report security vulnerabilities in public issues.

Use **Security → Report a vulnerability** in this repository (GitHub private vulnerability reporting).
Describe the affected endpoint, the environment (production / test) and the steps to reproduce.
Do not include real tokens, passwords or personal data.

Scope: the GlobKurier API (`api.globkurier.pl`, `test.api.globkurier.pl`) and this portal.
